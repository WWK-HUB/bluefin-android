# 鳍遇

「鳍遇」是一款可在手机上互动的安卓桌宠应用。你可以在应用里戳、拖、摸头、看动作，也可以在允许权限后，让它以系统悬浮窗的形式浮在其他应用上。

- 显示名：鳍遇
- 包名：`com.wwkhub.bluefin`
- 系统要求：Android 8.0 及以上

本仓库是蓝鳍安卓应用的源码。默认角色的原画和动作帧来自角色包仓库 [WWK-HUB/coopanion-bluefin-native](https://github.com/WWK-HUB/coopanion-bluefin-native)；那是角色素材仓库，不是本应用的源码仓库。

应用内互动不依赖网络。文字对话需要你自己填写 API 地址、模型名和 API Key（OpenAI 或 Anthropic 兼容接口），应用不内置官方模型密钥。

## 下载与安装

**[查看当前更新通道与 APK](https://github.com/WWK-HUB/bluefin-android/releases/tag/update-channel)**

首次安装时，在更新通道选择 `update-manifest.json` 指向的 APK。现有用户可在「设置 → 关于与更新 → 检查更新」覆盖安装，保留本机 API Key、对话、人设、角色和音色。若系统提示证书不一致，请先核对 APK 的分发来源，卸载会删除本机数据。

从源码构建请看[自行编译](#自行编译)。

## 功能

- **应用内互动**：轻点是戳（睡觉时可戳醒）；在头上来回滑动是摸头；按住拖动可提起，甩出后再松手会抛出。上方「动作」按当前角色自己的清单分「动作」「表情」两栏列出（内置蓝鳍与哑光冬装各 21 个动作、19 个表情，站立只列一次）。默认会沿画面底边自己走、跑、停，可在设置里关闭。
- **系统悬浮窗**（可选）：允许「显示在其他应用上层」后，角色和一颗功能小球会浮在其他应用上，仍可戳、拖、摸头。拒绝或关闭权限时，应用不会卡住，你可以继续只在应用内使用。
- **功能小球**：点开面板可播放当前角色能做的动作，调节角色大小、透明度、小球大小，开关底边走动、音效、点击穿透，隐藏悬浮窗或回到应用。小球可沿屏幕边缘拖动，位置会记住。横屏时面板同样可以完整滚动和操作。
- **外观调节**：角色大小约 0.50–1.30（默认 0.85），不透明度设定范围 0%–100%（滑向「透」更透明），小球大小 36–64 dp（默认 48 dp）。Android 12 及以上的系统悬浮窗会按设备的触摸遮挡限制封顶，小球面板会显示实际不透明度。应用内预览可使用 100%。
- **文字对话与人设**：在设置里选择 OpenAI 或 Anthropic 兼容格式，填写 API 地址、模型名和 API Key，即可在应用内「对话」页与悬浮窗「记录」里聊天，并可编辑人设。密钥只保存在本机应用私有存储，可随时清除。切换角色外观不会清空对话、人设或模型配置。
- **语音输入**：对话页和悬浮窗「记录」的输入框旁有麦克风键。点一下开始说话，再点一下结束，语音在本机离线识别成文字后自动发给宠物，宠物仍以文字回复。首次使用需下载一次约 78 MB 的中文语音模型；识别完全离线，音频不上传、不保存，也不改动你已配置的聊天模型。
- **朗读回复**：开启「自动朗读回复」后，宠物会读出新回复。云端合成使用 Fish Audio 免费模型，可按需安装本地 ZipVoice 作为备用。在 0.12.1-rc1 起，可录音、选文件或导入 ZIP 创建音色，试听独立于自动朗读开关。
- **角色包**：设置「角色」中可导入兼容的角色外观包（`.zip`，系统允许时也可选文件夹），并在内置蓝鳍和已导入外观之间切换。内置蓝鳍不可删除。应用不会从网上自动下载角色包。
- **点击穿透**：打开后，点到或滑过宠物的操作会落到下面的界面，方便操作被角色挡住的按钮和区域；小球和对话面板仍可正常使用。默认关闭，状态会记住。
- **对话气泡**：在小球里点「对话」，可直接在角色旁输入并查看流式回复。点回复可打开「记录」。关闭气泡或开启点击穿透后，可继续在「记录」里聊天。
- **屏幕观察**：系统授权后可让蓝鳍看一眼屏幕，也可以打开持续看屏，让蓝鳍根据画面主动发消息和说话。截图发送到你配置的视觉模型，持续看屏默认关闭。
- **应用内更新**：设置 → 关于 → 检查更新。当前更新源为 GitHub Releases（维护中的 `update-channel` 预发布标签托管清单与 APK）。**中国大陆网络可能无法直连 GitHub：若检查或下载失败，请切换可访问 GitHub 的网络（如代理）后重试**，应用内失败提示会写明这一点。下载前比对版本号，下载后校验包名、versionCode、SHA-256 与签名一致性，全部通过才交给系统安装器确认；可取消、失败可重试。客户端保留多源顺序回退能力，将来接入国内 HTTPS 主源只需改配置。

## 使用方法

### 悬浮窗权限

首次安装会显示五步新手指南，包含桌宠互动、悬浮窗、模型连接、语音和屏幕观察。每项设置都可稍后处理，指南可在「设置 → 新手指南」重看。

1. 点右上角悬浮窗按钮，或打开「设置 → 悬浮窗与气泡」里的「悬浮窗」开关。
2. 按提示允许「显示在其他应用上层」。不同品牌的入口名称可能略有差异，一般都在设置的特殊权限或应用权限里。
3. 允许后，角色会出现在其他应用上层，右侧是功能小球。点小球打开面板，拖动小球可沿屏幕边缘移动。
4. 若选择「先在应用内用」或未允许，应用不会反复弹窗，你仍可在应用内互动。以后要再用悬浮窗，到设置里打开「悬浮窗」，或点「重新询问悬浮窗权限」。

Android 13 及以上可从「悬浮窗与气泡 → 允许通知」授权。允许后可从通知栏回到蓝鳍、显示或隐藏悬浮窗，也可从屏幕观察的通知结束共享。

### 自填 API，开始对话

1. 打开「设置 → 模型连接」。
2. 按服务的文档选择 **接口格式**（OpenAI 兼容 Chat Completions 或 Anthropic 兼容 Messages），再填写 **API 地址**、**模型名** 和 **API Key**。升级后已有配置默认为 OpenAI 兼容。可按需要填写温度、最大输出 token 或附加请求头，并用「测试连接」检查。
3. 「测试连接」使用表单里当前填写的配置。点「保存并去对话」应用同一组地址、模型和 Key。密钥保存在本机应用私有存储里，可在设置里清除。
4. 到应用内「对话」页，或在悬浮窗小球里打开「记录」，即可聊天。还没填写时，应用会提示「去设置」，不会发出空请求。
5. 在「设置 → 人设」编辑，下一句对话生效。「清空对话」只删除聊天记录，模型配置和人设保留。

请使用你自己拥有访问权限的接口。不要把 API Key 发到聊天、截图或公开仓库。

### 语音输入

1. 在对话页或悬浮窗「记录」里点输入框旁的麦克风键。首次使用会先请求麦克风权限，并提示下载离线语音模型（约 78 MB，一次性，可在设置里删除重下）。
2. 点一下开始录音（状态行显示计时），再点一下结束。录音最长 60 秒，到限自动结束。
3. 识别在本机离线完成，文字会作为你的消息自动发送，宠物以文字回复。识别文字会显示在记录里；如果正在回复中，文字会先放进输入框，稍后可手动发送。
4. 说「看看我的屏幕」这类指令同样会触发屏幕观察流程。语音识别不需要网络，也不消耗聊天模型的流量；只有识别出的文字会走你配置的聊天接口。
5. 麦克风权限被拒绝时，打字聊天不受影响。设置「语音输入」里可以管理模型。

### 朗读回复

1. 到「设置 → 朗读回复」选择音色。开启「启用语音」后可手动重读，另开「自动朗读回复」可朗读每条新回复。「试听当前音色」只播放一次。
2. 云端语音服务会处理待朗读的回复。使用自制音色时，首次把该版本的参考录音及转录发送到所选服务前会询问，服务会保存副本用于后续朗读。录音和选文件保存音色时只写本机。
3. 在「自制与导入音色 → 管理我的音色」可删除本机和已知云端副本。离线时显示云端待删除，联网后自动重试。默认服务启用 90 天保留策略后，连续 90 天未活动会回收云端参考录音和设备名额。本机参考录音及云端会话凭据排除在系统备份和换机传输之外。
4. 可在「语音服务与缓存 → 离线备用设置」按需下载 ZipVoice（约 178 MB，一次性）。本地合成在设备上运行。

### 导入与切换角色包

1. 打开设置 →「角色」。列表第一项是内置「蓝鳍」，标记为「内置」，不可删除。
2. 点「导入角色包」，用系统文件选择器选择 `.zip` 角色包；如果系统允许，也可以选择包含角色包的文件夹。应用不会从网络下载角色包。
3. 导入成功后会询问是否立即切换。之后可随时点「使用」切换，或从小球面板的「更换角色」进入同一页。
4. 角色包有预设、配色或服装时，选中角色后可在它下方的「换装」里调整。每个角色保留自己的搭配。
5. 删除已导入角色需要确认；如果正在使用该角色，会切回内置蓝鳍。模型配置、对话记录和人设都不会因此改变。

导入支持 Coopanion 的 `figure.json`（manifest 2、API 2）角色包。角色包包含外观和动作，依赖桌面窗口的效果在手机上可能有差异。格式说明见 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion)。

体积超过 32 MiB 时会先提醒，超过 128 MiB 会拒绝；已导入角色最多 20 个（不含内置）。若某个角色不会自己走，走动开关仍在，但会提示「这个角色不会自己走」。

### 点击穿透

打开悬浮窗后，点功能小球，在面板里找到「点击穿透」（默认关闭）。

- **关闭（默认）**：点到角色时仍是戳、拖等互动，和往常一样。
- **打开**：点到或滑过角色的操作会落到下面的界面，被挡住的按钮和区域可以正常点击或滑动。悬浮窗本身还在，小球、展开后的面板和对话「记录」仍可操作。
- 关掉开关后，又可以重新戳、拖角色。开关状态会记住，隐藏后再打开悬浮窗仍然有效。

「点击穿透」和「暂停并隐藏」不是一回事。前者只是让手势穿过角色，角色仍然显示。

### 对话气泡

1. 填好模型设置，打开悬浮窗。设置中的「对话气泡」默认打开。
2. 点小球 →「对话」，在角色旁输入并发送。输入气泡的箭头可以带着草稿打开「记录」。
3. 生成时可点方形图标停止回复，点「×」关闭气泡。点回复正文可打开「记录」，回复结束后也可以点箭头，直接在应用内阅读完整对话。
4. 开启「点击穿透」或关闭「对话气泡」时，小球里的「对话」会打开记录面板。

### 屏幕观察

先在「设置 → 模型」中填好支持图片输入、兼容 Chat Completions 的模型。仅支持文字的模型可继续用来聊天。

- **按需看一眼**：在对话页或悬浮小球里点「看屏幕 · 直发」，也可以输入「蓝鳍，看看我的屏幕」。首次授权前会显示接收截图的模型，随后按系统提示选择共享范围。已有共享授权时，每次操作会直接发送一张截图。也可以从「屏幕观察 → 选截图」挑选图片，预览后确认发送。
- **持续看屏**：打开「屏幕观察 → 持续看屏」，输入 **15–3600 秒**的间隔（默认 **30 秒**），并完成系统授权。蓝鳍会按间隔检查共享画面，遇到值得聊的新内容时主动把评论发到对话里。桌面回复气泡可用时，也会显示这条评论。开启「启用语音」和「自动朗读回复」后会读出评论。画面相同或正在处理用户消息时会跳过。「屏幕观察」会显示最近检查和画面摘要。
- **结束共享**：关掉「持续看屏」，或使用共享通知里的「停止观察」。锁屏后观察也会停止。

截图在手机端只在内存中处理，会发送到你配置的模型服务。Android 14 及以上可以在系统授权中选择仅共享一个应用，也可以共享整个屏幕。单应用切出可见范围时暂停采集，切回后可以重新看屏。

## 自行编译

需要 JDK 17 或更高，以及 Android SDK Platform 35。在系统或 `local.properties` 中设置 SDK 路径，例如：

```properties
sdk.dir=/你的/Android/Sdk
```

`local.properties` 不要提交。

在含有 `gradlew` 的目录执行（若工程在 `android/` 子目录，先进入该目录）：

```bash
chmod +x ./gradlew
./gradlew assembleDebug
```

调试包输出为：

```text
app/build/outputs/apk/debug/app-debug.apk
```

签名是本机 Android debug 证书，只适合自己侧载。打包前请确认 `app/src/main/assets/bluefin/index.html` 及配套资源已在工程内。若希望缺少这份入口时直接构建失败，可加上 `-PrequireRouteB=true`。

语音识别依赖仓库内的 `app/libs/sherpa-onnx-2.0.1.aar`（Apache-2.0，来自 sherpa-onnx v2.0.1 发布）。默认只打包 arm64-v8a 原生库；需要在 x86_64 模拟器上验证时加 `-PvoiceX86=true`。中文语音模型不打进 APK，由应用内按需下载。

朗读回复复用同一个 AAR（ZipVoice + Vocos 走同一套 JNI），引擎五件套同样不打进 APK：构建后把它们上传到本仓库的 `tts-models` 预发布标签，应用按 `OfflineTtsSpec.urlsFor()` 里的顺序（gh-proxy 优先、GitHub 直连兜底）下载。模型清单与体积见 `voice/tts/OfflineTtsSpec.kt`。两个内置音色的参考录音在 `app/src/main/assets/voice-packs/`，可用 `python scripts/make-voice-pack.py` 从原始录音重新切分生成。
