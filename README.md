# 蓝鳍

「蓝鳍」是一款可在手机上互动的安卓桌宠应用。你可以在应用里戳、拖、摸头、看动作，也可以在允许权限后，让它以系统悬浮窗的形式浮在其他应用上。

- 显示名：蓝鳍
- 包名：`com.wwkhub.bluefin`
- 安装方式：侧载 APK，不在应用商店上架
- 系统要求：Android 8.0 及以上

本仓库是蓝鳍安卓应用的源码。默认角色的原画和动作帧来自角色包仓库 [WWK-HUB/coopanion-bluefin-native](https://github.com/WWK-HUB/coopanion-bluefin-native)；那是角色素材仓库，不是本应用的源码仓库。

应用内互动不依赖网络。文字对话需要你自己填写 API 地址、模型名和 API Key（OpenAI 兼容接口），应用不内置官方模型密钥。

**版本说明：** 当前源码是 **0.8.0-rc1** 开发候选版，支持在悬浮窗气泡中输入和查看回复。最近一次已确认可用的基线为 **0.6.0-rc3**。

## 功能

- **应用内互动**：轻点是戳（睡觉时可戳醒）；在头上来回滑动是摸头；按住拖动可提起，甩出后再松手会抛出。上方「动作」可切换挥手、行走、跑步、跳舞、睡觉等。默认会沿画面底边自己走、跑、停，可在设置里关闭。
- **系统悬浮窗**（可选）：允许「显示在其他应用上层」后，角色和一颗功能小球会浮在其他应用上，仍可戳、拖、摸头。拒绝或关闭权限时，应用不会卡住，你可以继续只在应用内使用。
- **功能小球**：点开面板可播放当前角色能做的动作，调节角色大小、透明度、小球大小，开关底边走动、音效、点击穿透，隐藏悬浮窗或回到应用。小球可沿屏幕边缘拖动，位置会记住。横屏时面板同样可以完整滚动和操作。
- **外观调节**：角色大小约 0.50–1.30（默认 0.85），透明度 0%–100%（默认不透明，滑向「透」更透明），小球大小 36–64 dp（默认 48 dp）。
- **文字对话与人设**：在设置里自行填写 OpenAI 兼容的 API 地址、模型名和 API Key，即可在应用内「对话」页与悬浮窗「记录」里聊天，并可编辑人设。密钥只保存在本机应用私有存储，可随时清除。切换角色外观不会清空对话、人设或模型配置。
- **角色包**：设置「角色」中可导入兼容的角色外观包（`.zip`，系统允许时也可选文件夹），并在内置蓝鳍和已导入外观之间切换。内置蓝鳍不可删除。应用不会从网上自动下载角色包。
- **点击穿透**：打开后，点到或滑过宠物的操作会落到下面的界面，方便操作被角色挡住的按钮和区域；小球和对话面板仍可正常使用。默认关闭，状态会记住。
- **对话气泡**：在小球里点「对话」，可直接在角色旁输入并查看流式回复。点回复可打开「记录」。关闭气泡或开启点击穿透后，可继续在「记录」里聊天。

不含语音对话、电脑控制，也不内置官方模型密钥。

## 更新历史

面向使用者，按已经对用户开放的能力归并。中间调试包不一一列出。

### 0.8.0-rc1（开发候选版）

- 悬浮窗新增头顶输入气泡，支持多行草稿、发送、停止生成与展开记录。
- 键盘弹出时，输入框移到可见区域。切换到记录面板会带上当前草稿。
- 应用内对话和悬浮记录只更新有变化的消息。向上浏览历史时，新回复不会强制把页面滚回底部。

### 0.7.0-rc1

- 新增悬浮窗对话气泡：在角色旁预览本轮对话，回复逐字出现；点气泡或「记录」可继续看历史、继续聊。
- 设置 → 悬浮窗 中增加「对话气泡」总开关，默认打开。
- 开启「点击穿透」时自动不显示气泡，避免挡住下层界面；输入和回复仍可在「记录」里完成。
- 此前已有的互动、悬浮窗、对话、人设、角色包和点击穿透均保留。

这一版还不是已确认的稳定基线。若气泡显示异常，可在设置里关掉「对话气泡」，改用「记录」和应用内对话页。

### 0.6.0-rc3（已确认可用的基线）

- 小球面板增加「点击穿透」开关，默认关闭：关闭时仍可戳、拖宠物；打开后，点按和滑动会穿透到下层应用，小球和对话面板保持可操作。关窗再开窗，开关状态仍在。
- 可在设置「角色」中导入并切换兼容的角色外观包；内置蓝鳍不可覆盖或删除。切换外观不重置模型、对话记录和人设。
- 动作面板只列出当前角色实际能做的动作；若角色包带换装，可在「角色」里选择。

### 更早已具备、并包含在 0.6.0-rc3 中的能力

- 应用内可玩预览：戳、摸头、提起、抛出，以及动作和底边走动。
- 可选的系统悬浮窗与常驻通知（用于回到应用、显示或隐藏悬浮窗）；拒绝权限时可继续在应用内使用，设置里可重新开启或再次询问。
- 自行填写 API 的文字对话，以及人设编辑；清空对话不会丢掉模型配置和人设。
- 角色大小、透明度、小球大小等调节；主界面以舞台为主，动收进面板。

## 使用方法

### 侧载安装

把 APK 拷到手机后安装。系统会要求允许「安装未知应用」。

1. 用数据线、网盘或聊天文件把 APK 放到手机。
2. 打开设置，允许来自当前安装入口（文件管理器、浏览器或聊天应用）的未知应用：
   - 原生 / Pixel：设置 → 应用 → 特殊应用权限 → 安装未知应用 → 选中正在用来打开 APK 的应用 → 允许
   - 小米：设置 → 隐私保护 → 特殊权限 → 安装未知应用
   - 华为：设置 → 安全 → 更多安全设置 → 外部来源应用下载
   - 若点开 APK 时系统弹出拦截，按提示打开该应用的「允许来自此来源」
3. 回到文件管理器，点开 APK，确认应用名为「蓝鳍」，再继续安装。
4. 若你在电脑上使用调试桥，也可以执行：

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

（若工程在仓库的 `android/` 目录下，请把路径改成 `android/app/build/outputs/apk/debug/app-debug.apk`。）

打开「蓝鳍」。首次会看到三步互动提示，可跳过，状态记在本机。Android 13 及以上可能会询问通知权限，用于显示常驻通知（「点按回到蓝鳍」，以及「显示悬浮窗」「隐藏悬浮窗」）。通知本身不是悬浮窗。

卸载：在系统应用列表中卸载「蓝鳍」。

用不同电脑打出的调试包，覆盖安装有时会失败，先卸载再装即可。卸载会清除本机保存的 API Key、对话和已导入角色包。

### 悬浮窗权限

1. 点右上角悬浮窗按钮，或打开设置里的「悬浮窗」开关。
2. 按提示允许「显示在其他应用上层」。不同品牌的入口名称可能略有差异，一般都在设置的特殊权限或应用权限里。
3. 允许后，角色会出现在其他应用上层，右侧是功能小球。点小球打开面板，拖动小球可沿屏幕边缘移动。
4. 若选择「先在应用内用」或未允许，应用不会反复弹窗，你仍可在应用内互动。以后要再用悬浮窗，到设置里打开「悬浮窗」，或点「重新询问悬浮窗权限」。

### 自填 API，开始对话

1. 打开设置，找到「模型」。
2. 填写 **API 地址**、**模型名** 和 **API Key**。接口需兼容 OpenAI 的 Chat Completions。可按需要填写温度、最大输出 token 或附加请求头，并用「测试连接」检查。
3. 保存。密钥只写在本机应用私有存储里，不会上传到本应用的服务器；设置里可以清除密钥，地址和模型名会保留。
4. 到应用内「对话」页，或在悬浮窗小球里打开「记录」，即可聊天。还没填写时，应用会提示「去设置」，不会发出空请求。
5. 同一页可以编辑「人设」，下一句对话生效。「清空对话」只删除聊天记录，不会丢掉模型配置和人设。

请使用你自己拥有访问权限的接口。不要把 API Key 发到聊天、截图或公开仓库。

### 导入与切换角色包

1. 打开设置 →「角色」。列表第一项是内置「蓝鳍」，标记为「内置」，不可删除。
2. 点「导入角色包」，用系统文件选择器选择 `.zip` 角色包；如果系统允许，也可以选择包含角色包的文件夹。应用不会从网络下载角色包。
3. 导入成功后会询问是否立即切换。之后可随时点「使用」切换，或从小球面板的「更换角色」进入同一页。
4. 删除已导入角色需要确认；如果正在使用该角色，会切回内置蓝鳍。模型配置、对话记录和人设都不会因此改变。

可导入与 [Coopanion](https://github.com/Pal-AI-Lab/Coopanion) 兼容的角色外观包（本应用按常见的 `figure.json` 角色包格式读取）。这只改变外观和动作，不会把桌面版 Coopanion 的对话、记忆或 API 设置搬进来，也不需要先安装桌面版才能使用本应用。

体积超过 32 MiB 时会先提醒，超过 128 MiB 会拒绝；已导入角色最多 20 个（不含内置）。若某个角色不会自己走，走动开关仍在，但会提示「这个角色不会自己走」。

### 点击穿透

打开悬浮窗后，点功能小球，在面板里找到「点击穿透」（默认关闭）。

- **关闭（默认）**：点到角色时仍是戳、拖等互动，和往常一样。
- **打开**：点到或滑过角色的操作会落到下面的界面，被挡住的按钮和区域可以正常点击或滑动。悬浮窗本身还在，小球、展开后的面板和对话「记录」仍可操作。
- 关掉开关后，又可以重新戳、拖角色。开关状态会记住，隐藏后再打开悬浮窗仍然有效。

「点击穿透」和「暂停并隐藏」不是一回事。前者只是让手势穿过角色，角色仍然显示。

### 对话气泡

1. 填好模型设置，打开悬浮窗。设置中的「对话气泡」默认打开。
2. 点小球 →「对话」，在角色旁输入并发送。输入气泡的箭头可以带着草稿打开「记录」。
3. 生成时可点方形图标停止回复，点「×」关闭气泡。点回复正文可打开「记录」，回复结束后也可以点箭头，直接在应用内阅读完整对话。
4. 开启「点击穿透」或关闭「对话气泡」时，小球里的「对话」会打开记录面板。

## 自行编译

需要 JDK 17 或更高，以及 Android SDK Platform 35。在系统或 `local.properties` 中设置 SDK 路径，例如：

```properties
sdk.dir=/你的/Android/Sdk
```

`local.properties` 不要提交。

在含有 `gradlew` 的目录执行（若工程在 `android/` 子目录，先进入该目录）：

```bash
chmod +x ./gradlew
./gradlew assembleDebug
```

调试包输出为：

```text
app/build/outputs/apk/debug/app-debug.apk
```

签名是本机 Android debug 证书，只适合自己侧载。打包前请确认 `app/src/main/assets/bluefin/index.html` 及配套资源已在工程内。若希望缺少这份入口时直接构建失败，可加上 `-PrequireRouteB=true`。
